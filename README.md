# AI金种子 · 备考练习室

依据7份培训资料编制的360道客观练习题，支持手机与电脑浏览器。

| 题型 | 数量 |
| --- | ---: |
| 单选 | 180 |
| 多选 | 108 |
| 判断 | 72 |

章节分布：目标架构70题、联创试点60题、场景选择70题、四大工程70题、iCode35题、AIxCoding25题、10月宣讲30题。

每题提供答案、解析、原文摘录及页码。原始PPT/PDF不包含在本仓库中。练习题由AI根据资料整理，不代表正式考试原题或官方考试规则。

## 使用功能

- 章节、题型、作答状态筛选，关键词搜索，30题分页浏览。
- 顺序及随机练习，收藏，错题重练，逐题来源核对。
- 20/50/100题随机模拟，每卷覆盖7章，题型比例5:3:2，无重复题。
- 多选完全匹配才得分，未答计错，百分制，本站练习目标80分。
- 375px手机适配、底部导航、固定答题操作栏、抽屉答题卡、大号点选区。
- 浏览器本地保存进度，刷新恢复未完成答题与考试计时，可导出和导入JSON备份。

进度不会跨设备自动同步。更换域名或设备时，可在“学习记录”页导出备份，再在新设备导入。

## 本地预览

```sh
python3 -m http.server 8765 --directory docs
```

然后访问 http://127.0.0.1:8765 。请通过HTTP服务打开，直接双击HTML可能限制题库读取。
